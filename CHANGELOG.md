# Чейнджлог IkuraDroid

Здесь только изменения самого IkuraDroid. История старого Android-порта 2015–2016 годов вынесена в README и архивную тему VK.

## 1.9.8 — 2026-09-17

- «О программе» теперь открывается как модальное окно в стиле меню по долгому нажатию на плитку, а не отдельным экраном.
- Добавлен свайп сверху вниз для закрытия игровых окон. По поведению это Escape на PC.
- Меню можно открывать свайпом снизу вверх из любой точки экрана. Обычные тап- и drag-жесты при этом продолжают доходить до игры.
- Добавлен дополнительный лог для кнопки `Exit` в диалогах сохранения/загрузки. В logcat теперь видно координаты клика и результат hit-test; touch-события движка тоже логируются с нормализованными и логическими координатами.
- Исправлен чёрный экран при повторном запуске игры. Игровой процесс отделён от библиотеки.
- Добавлены отдельные сообщения о стадиях запуска в logcat (`ikuradroid`).
- Ошибка создания SDL-рендерера больше не игнорируется: `InitVideo` завершается с ошибкой, вместо запуска движка с чёрным экраном.
- На старте новой сессии сбрасывается перечислитель каталогов `EDL_GetFileReset`, чтобы после прерванного выхода не использовать старый `DIR*`.
- Встроенный SDL обновлён с 2.0.3 до 2.30.12. Заодно обновлён Android glue и адаптированы запуск игры, меню и пауза микшера.
- Исправлено зависание библиотеки после выхода из игры. Native-поток теперь завершается штатно, а следующая сессия получает чистые настройки.
- Контекстное меню плитки теперь учитывает safe-area и не перекрывает системную навигацию.
- Critical Point: подсветка выбора теперь повторяет PC-версию — инвертируется строка выбора, а на таче подсветка следует за пальцем и фиксируется при отпускании.
- Critical Point: координаты блока выбора подогнаны по PC-скриншотам; строки идут сплошным блоком без мёртвых зон.
- Исправлен размер игрового окна после перехода на SDL 2.30. Игра снова масштабируется на весь экран.
- На Android отключён синтез mouse-событий из touch: движок получает чистый touch-ввод.
- В игре снова скрываются статус-бар и панель навигации. Immersive mode повторно включается при возврате фокуса.
- Исправлен «мёртвый» экран библиотеки после выхода через меню. Теперь native-поток получает QUIT и корректно завершается, а `join()` больше не блокируется на спящем SDL-потоке.
- На Android QUIT теперь завершает игру без отдельного диалога подтверждения. Подтверждение остаётся за игровыми меню и desktop-версией.
- Critical Point: строки выбора увеличены до 32 px по высоте и шагу, чтобы по ним было проще попадать пальцем.

## 1.9.7 — 2026-09-11

- Critical Point: исправлен чёрный экран во время событий. Многослойная EV-графика из WIPF теперь собирается из нескольких кадров.
- Critical Point: текстовое окно и координаты текста выровнены по PC-версии.
- Critical Point: выборы снова рисуются внутри текстового окна, как в оригинале. Зоны нажатия растянуты на всю ширину строки.
- Critical Point: исправлено съедание первых двух букв выбора. Для CP больше не читается параметр, который относится только к Little My Maid.
- После выхода из игры через меню приложение больше не остаётся в landscape.
- Сборка: minSdk поднят до 24; CI-воркфлоу удалены, APK собирается локально. Подпись релиза стала опциональной.
