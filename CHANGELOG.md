# Чейнджлог IkuraDroid

Здесь только изменения самого IkuraDroid. История старого Android-порта 2015–2016 годов вынесена в README и архивную тему VK.

## 2.5.0 — 2026-10-01

- Heart de Roommate: добавлено настоящее текстовое окно с графикой из файлов игры, и выборы в диалогах теперь работают. Текст рисуется шрифтом из ресурсов приложения, а не встроенным в движок. Текстовое окно выводится без искажений, а сценарий больше не зависает с пустым экраном.
- Heart de Roommate: диалог выровнен по PC-версии. Имя говорящего — в верхней строке, реплика — ниже, межстрочный интервал как в оригинале. Повествование и продолжение страниц больше не сбиваются на строку имени.
- Heart de Roommate: добавлены имена говорящих, которых оригинал не показывал, — они берутся из данных русского релиза. Повествование остаётся без имени.
- Heart de Roommate: исправлен прозрачный вывод 24-битных изображений. Картинка больше не закрывается чёрным прямоугольником; 32-битный `GGA` продолжает использовать обычную альфу.
- Ikura: добавлено воспроизведение MPEG-1 видео через `pl_mpeg`. Поддерживаются видео из архива и обычные `.mpg`/`.avi` в папке игры; `Critical Point` может использовать `.dat` с MPEG-потоком. Видео можно пропустить тапом по экрану; в PC-сборке — кликом мыши или любой клавишей.
- Ikura: добавлено воспроизведение CD-DA треков из `WMSC`. Также исправлено чтение сжатых WAV из `Crescendo` — IMA ADPCM теперь декодируется нормально.
- Ikura: добавлены анимации переходов `GP 15/16/17` и поддержка `GSCRL (0x62)` для панорамирования увеличенной VRAM-поверхности. Заодно исправлено выравнивание 24-битного `GGD`.
- Тач: ввод теперь ближе к поведению PC — подсветка выбора видна во время нажатия и фиксируется при отпускании. Исправлен сдвиг координат кликов на широких экранах — letterbox-математика применялась второй раз.
- Сохранения: нативные Android-вызовы сохранения/загрузки переведены на Java-диалог со слотами. Доступны 40 слотов, скриншоты, дата и подпись сцены. Исправлено отображение кириллицы и сохранение в пустые слоты.
- Библиотека: плитки получили формат 2:3 и обложки из VNDB. Добавлен автоматический поиск обложек, кэш и ручное удаление обложки. Тайтлы Ikura GDL можно автоматически назвать по `SUF`.
- Выход из игры на Android больше не показывает второй раз `Exit game?`, если пользователь уже нажал выход внутри самой игры. Сохранение перед выходом остаётся.
- Пункт «Настройки» в игровом меню пока отключён и показывает уведомление о том, что функция появится позже.
- Little My Maid снова отмечен как непроверенный модуль.
- Убраны оставшиеся упоминания `vilevn.pck`: файл больше не нужен, поэтому он также исчез из подсказок и обычного лога.

## 2.0.6 — 2026-09-21

- Crescendo: восстановлено воспроизведение музыки на заставке, в меню и во время игры. `SE` и `WMSC` теперь читаются как нативные `SM2MPX10`; MIDI-банк берётся из отдельного MIDI-файла.
- Исправлено воспроизведение WAV с IMA ADPCM.
- Critical Point: исправлен перевёрнутый вид миниатюр сохранений на части устройств.
- Critical Point: после загрузки сохранения восстанавливается музыка текущей сцены. Для новых сохранений трек записывается в сейв; старые сейвы работают как раньше.
